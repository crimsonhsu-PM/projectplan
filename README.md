# RSG Project Plan

可編輯 Epic 與工作項目的專案排程系統，提供每日甘特圖、人力視圖、匯入與匯出。

## 功能

- Epic／工作項目管理與排序
- 每日甘特圖、工作日與進度計算
- 人力排程彙總、試算表匯入／匯出
- Cloudflare D1 保存專案資料

Demo：https://rsg-project-plan.lazyer1016.chatgpt.site

## 本機啟動

```bash
git clone https://github.com/crimsonhsu-PM/projectplan.git
cd projectplan
pnpm install
pnpm dev
```

瀏覽終端顯示的本機網址。測試、部署與搬遷詳見 [HANDOFF.md](HANDOFF.md)。
